\projectsep

\textbf{Liquid Time：基于 Patch 的液态神经网络长时间序列预测模型} \hfill 2026年1月 -- 至今 \titlebreak
提出 Liquid Time，一种面向长时间序列预测的端到端建模框架，将 patch 级时间表征学习与基于 CfC 的连续时间递归动态建模相结合，以提升长预测跨度下的鲁棒预测能力；已完成完整学术论文撰写，并投稿至 EI 检索会议。

\begin{itemize}
    \item \textbf{模型框架}：集成 RevIN 归一化、时间 patch 嵌入、基于 CfC 的动态编码器以及轻量级 MLP 预测头，以改善非平稳时间序列条件下的长期预测性能。
    \item \textbf{核心思想}：设计 patch 级 CfC 建模策略，将长历史序列压缩为局部时间单元，并学习 patch 之间的连续时间转移关系，在降低递归建模深度的同时保留局部抽象能力与长程时间动态。
    \item \textbf{实验结果}：在六个公开基准数据集上取得持续具有竞争力的结果；在 ETTh1 数据集全部预测长度上取得最优 MSE，并在 ETTh1-336 与 ETTh2-336 设置下相较最强竞争基线分别降低 MSE 9.7\% 与 12.1\%。
    \item \textbf{模型分析}：完成消融实验与超参数敏感性分析，验证 patch 划分、CfC 骨干网络、RevIN 归一化、预测头设计以及位置编码对模型性能的贡献。
\end{itemize}
